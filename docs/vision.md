# Visión

Quini6AI no pretende predecir el azar.

Su objetivo es ayudar al usuario a analizar información,
evaluar estrategias y generar combinaciones utilizando
criterios estadísticos configurables.

El sistema debe ser:

- Modular.
- Auditable.
- Reproducible.
- Extensible.
- Fácil de utilizar por personas sin conocimientos técnicos.

Toda decisión tomada por el motor deberá poder ser
explicada mediante reglas, estadísticas y configuraciones,
evitando comportamientos opacos.
