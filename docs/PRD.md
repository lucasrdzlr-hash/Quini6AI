# Quini6AI

## Product Requirements Document

Versión objetivo: 1.0

---

# Objetivo

Quini6AI es una plataforma profesional para administrar el
historial del Quini 6, analizar estadísticas, probar
estrategias y generar jugadas utilizando un motor
estadístico extensible mediante plugins configurables.

El objetivo NO es predecir el azar.

El objetivo es ayudar al usuario a tomar decisiones
utilizando información objetiva.

---

# Público

• Jugadores avanzados

• Analistas estadísticos

• Investigadores

• Desarrolladores

---

# Principios

Todo debe poder explicarse.

Toda decisión debe poder reproducirse.

Todo algoritmo debe poder activarse o desactivarse.
