# Quini6AI

Motor estadístico para generación y evaluación de jugadas del Quini 6.

## Arquitectura

```
Q2.xlsx
    │
Provider
    │
FeatureEngine
    │
ScoreEngine
    │
WeightedGenerator
    │
Evaluator
    │
ExcelWriter
```

## Ejecutar

```bash
py main.py
```

## Dependencias

```bash
pip install -r requirements.txt
```
